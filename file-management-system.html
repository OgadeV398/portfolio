Project Overview

The File Management System is a Node.js command-line tool that lets users interact with their file system straight from the terminal. Users can create, read, rename, move and delete files and folders using short, easy-to-remember commands.

The Problem

Managing files through long, complex shell commands can be confusing, especially for beginners. There was a need for a simpler and friendlier way to handle everyday file and folder tasks from the terminal.

Key Features

  • Create and delete files and folders
  • Read, rename and move files
  • List directory contents clearly
  • Simple, beginner-friendly commands

Technologies Used

Node.js
CLI

What I Learned

I learned how to work with Node.js’s built-in fs and path modules, handle asynchronous operations, and parse command-line input. It also taught me the importance of good error handling when working with files.
