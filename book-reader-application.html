Project Overview

The Book Reader Application is a command-line tool that connects to an external books API so users can search for titles, browse results and view book details right from the terminal. It was built to make finding and exploring books fast, lightweight and distraction-free.

The Problem

Finding information about a book usually means opening a browser, wading through ads and jumping between sites. Developers and terminal lovers needed a quick, focused way to search and read about books in one place.

Key Features

  • Search books by title or author
  • Fetch live data from an external API
  • View detailed book information
  • Fast, lightweight terminal interface

Technologies Used

Node.js
Express.js
MongoDB
CLI

What I Learned

I learned how to consume and handle data from an external API, structure a backend with Express, and store data with MongoDB. It also taught me how to design a clear, friendly experience inside the terminal.
